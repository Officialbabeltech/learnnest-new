# LearnNest starter

This is a clean responsive purple-and-white LearnNest starter.

## Files
- `index.html` — page structure
- `styles.css` — responsive layout and design
- `main.js` — mobile navigation, subject search, and subject topic dialogs

## Publish with GitHub Pages
1. Upload `index.html`, `styles.css`, and `main.js` to the root of this repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.

This first version does not connect Firebase yet. We should publish and test the basic site before adding sign-in or database features.
